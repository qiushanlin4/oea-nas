# 01 · 硬件与接线

## 设备规格

| 项目 | 值 |
|---|---|
| 型号 | 网心云 OEA（OneCloud Edge Appliance） |
| 板号 | `OEA-A-V1.0` |
| SoC | Rockchip **RK3318**（U-Boot 报 `Model: Hugsun RK3328 wx oea v16 avb`） |
| 内存 | 1 GB DDR3（实测可用 950 MB，频率 333 MHz） |
| 存储 | 128 GB eMMC（海康，`122,142,720` KB） |
| 网口 | 百兆以太网（`rk_gmac-dwmac ff550000.ethernet`） |
| WiFi | **无** |
| HDMI | **无**（未引出） |
| SD 卡槽 | **无** |
| USB | 1 个 USB-A，实际是 OTG（`dwc2 ff580000.usb`），但**设备端 OTG 未引出** |
| 串口 | 4 孔，丝印 `RX TX GND` + 第 4 针 3V3（方盘） |

### 实际尺寸与拆解

盒子是塑料外壳，四颗螺丝。拆开后 PCB 上能看到的：

- eMMC 芯片（BGA 封装，带散热贴）
- SoC（RK3318，压在屏蔽罩下）
- 4 个镀金 UART 孔，旁边有丝印
- 一排 2×5 金孔阵列（**是无铜过孔，不是测试点**）

## 串口接线

### 引脚定义

板子上 4 个孔，按丝印从左到右：

```
  RX    TX    GND   [3V3]
   │     │     │      │
   │     │     │      └── 方盘标记，不要接
   │     │     └───────── GND
   │     └─────────────── 接 CH340 的 RX
   └───────────────────── 接 CH340 的 TX
```

**注意 TX/RX 是交叉的**：板子的 TX 接模块的 RX，板子的 RX 接模块的 TX。

### CH340 模块设置

1. **跳线帽拨到 3.3V**（默认可能是 5V，接错会烧板）
2. **VCC 引脚悬空不接** —— 板子自己供电
3. 只接 3 根线：GND、TX、RX

### 常见错误

| 错误 | 后果 |
|---|---|
| VCC 接到板子 | **可能烧毁** |
| 跳线在 5V | 可能烧毁 |
| TX/RX 接反 | 不会烧，只是看不到输出 → 对调即可 |
| GND 没接 | 乱码或完全无输出 |

### 串口参数

```
波特率: 1500000
数据位: 8
校验位: None
停止位: 1
流控:   None
```

**1500000 是非常规波特率**，很多终端软件不支持。Windows 上推荐：

- PuTTY（支持任意波特率）
- 我们写的 PowerShell 脚本（见 [03-uart-fiq.md](03-uart-fiq.md)）

Linux/macOS：
```bash
stty -F /dev/ttyUSB0 1500000 raw -echo
cat /dev/ttyUSB0
```

### 如果 1500000 打不开

有些 CH340 克隆芯片最高只支持 921600。测试方法：

```bash
# 依次尝试
for baud in 1500000 921600 460800 115200; do
    echo "=== $baud ==="
    stty -F /dev/ttyUSB0 $baud raw -echo 2>/dev/null && timeout 3 cat /dev/ttyUSB0 | head -5
done
```

如果只有 115200 能打开，说明串口芯片不支持 —— 但**板子跑的一定是 1500000**，你会看到乱码。
换个模块（FT232 或 CP2102 都支持）。

## 网络接线

### 方案 A：直连电脑（推荐用于刷机阶段）

```
板子 ──── 网线 ──── 电脑网口
```

电脑网卡手动设成静态 IP：

| 项目 | 值 |
|---|---|
| IP | `10.9.8.10` |
| 掩码 | `255.255.255.0` |
| 网关 | 留空 |

这样板子启动后会自动配 `10.9.8.77`（见 [07-network.md](07-network.md)）。

### 方案 B：接路由器（最终使用形态）

```
板子 ──── 网线 ──── 路由器 LAN 口
```

板子会自动 DHCP 拿地址，同时**保留** `10.9.8.77` 作为救援地址。
两个地址同时存在，互不干扰。

---

## 电源

原装 12V 电源。**不要用 POE**（这块板不支持）。

实测功耗：
- 待机：约 3 W
- SMB 满速传输：约 5 W

## 硬件限制速查

| 想做的事 | 能不能 | 说明 |
|---|---|---|
| 接显示器 | ❌ | HDMI 未引出 |
| 接 USB 硬盘 | ⚠️ | USB-A 口是 OTG，设备端未引出，插 U 盘无反应 |
| 加 WiFi 模块 | ❌ | 没有 USB 口可用，也没有 M.2/miniPCIe |
| 插 SD 卡 | ❌ | 没有卡槽 |
| 换更大 eMMC | ❌ | BGA 封装，需要专业返修台 |
| 加内存 | ❌ | 板载 DDR3，焊死 |

**这块板子只能做 NAS。** 1 GB 内存 + 百兆网口 + 128 GB eMMC，定位就是轻量文件服务器。
